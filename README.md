# 📊 Expertego - Power BI Templates Library

Bienvenido al repositorio oficial de plantillas de Power BI de **Expertego**. Aquí compartimos recursos diseñados para ayudar a arquitectos de soluciones, líderes de TI y especialistas en seguridad a visualizar datos complejos de manera accionable.

## 🚀 Acerca de este Repositorio
Este espacio centraliza tableros (archivos `.pbit`) enfocados en gobernanza, infraestructura y seguridad cloud. Cada plantilla está diseñada siguiendo las mejores prácticas de visualización y optimización de modelos de datos.

| Reporte | Categoría | Descripción |
| :--- | :--- | :--- |
| [**Identity Governance Entra ID**](./Identity-Governance-EntraID) | Seguridad | Visualización de roles, asignaciones PIM y salud de identidades. |
| *Próximamente...* | FinOps | Gestión de costos en Azure. |

## 🛠️ Cómo usar estas plantillas
1. Navega a la carpeta del reporte que te interesa.
2. Lee el `README.md` específico de ese reporte para conocer los requisitos de datos.
3. Descarga el archivo `.pbit`.
4. Abre el archivo en **Power BI Desktop**, introduce los parámetros solicitados y conecta tus datos.
